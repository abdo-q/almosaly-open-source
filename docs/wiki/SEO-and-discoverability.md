# SEO والاكتشاف

## الهدف

يستهدف المشروع جمهورين متكاملين:

1. مطورو Android والويب الذين يبحثون عن مشروع إسلامي مفتوح المصدر أو إعادة بناء Apktool/Smali موثقة.
2. المستخدمون الذين يبحثون عن تطبيق مصلي ويب خفيف لمواقيت الصلاة والقرآن والأذكار والقبلة مع احترام الخصوصية.

لا تُستخدم الكلمات المفتاحية لإخفاء محتوى أو تكراره آليًا؛ يجب أن تكون كل صفحة مفيدة للزائر.

## تطبيقها في المشروع

- يحتوي README العربي على وصف دقيق وروابط التنزيل والمساهمة.
- يوفّر `README.en.md` مدخلًا للمطورين الدوليين.
- يضم وصف GitHub Topics تقنية ووظيفية، مثل `android`, `open-source`, `pwa`, `islamic-app`, `prayer-times`, `quran`, `azkar`, `smali`, و`apktool`.
- تحتوي الصفحة الرئيسية للموقع على title وdescription وOpen Graph وTwitter Card وcanonical URL.
- يوفّر الموقع `robots.txt` و`sitemap.xml` للصفحة العامة.
- لا تُفهرس بيانات المستخدم المحلية أو الإعدادات الشخصية؛ فلا توجد حسابات أو قاعدة بيانات عامة.

## مراجعة دورية

راجع العناوين والوصف والروابط عند كل إصدار. قِس نجاح SEO من خلال الزيارات والروابط المفيدة ومشكلات الاستخدام، وليس من خلال تكرار الكلمات فقط.
