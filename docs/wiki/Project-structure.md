# هيكلة المشروع

## نظرة على الجذر

```text
.
├── README.md                 # تعريف Android والويب وإرشادات البناء
├── CONTRIBUTING.md           # المساهمة في Android أو الموقع الثابت
├── LICENSE                   # ترخيص المستودع؛ راجع حقوق كل مورد على حدة
├── scripts/build-release.sh  # بناء ومحاذاة وتوقيع APK بمفتاح يقدمه المستخدم
├── assets/images/            # صور README ومصادرها
├── docs/wiki/                # صفحات التوثيق التفصيلية
├── website/                  # تطبيق ويب ثابت مستقل
└── app/                      # مشروع Android المفكك عبر Apktool
```

## موقع الويب `website/`

| المسار | الغرض |
| --- | --- |
| `index.html`, `src/App.tsx` | نقطة دخول React وتوجيه hash الملائم لمسار GitHub Pages |
| `src/pages/` | الصفحة الرئيسية، القرآن، الأذكار، القبلة، التقويم، الختمة والإعدادات |
| `src/components/` | هيكل التنقل والهوية المرئية |
| `src/lib/localData.tsx` | تخزين تفضيلات ومفضلات وتقدم محليًا في المتصفح |
| `src/lib/prayer.ts` | حساب مواقيت الصلاة والقبلة بالتوقيت وطريقة الحساب المختارة |
| `src/lib/quran.ts` | طلب قائمة السور والسورة المختارة من AlQuran Cloud |
| `public/` | الشعار واللقطات وأيقونات/ملفات PWA وبيان المسارات |
| `SOURCES.md`, `README.md` | نسب المصادر والتراخيص وتعليمات التطوير والبناء |
| `vite.config.ts`, `package.json`, `pnpm-lock.yaml` | أداة البناء واعتمادياته المثبتة |
| `.github/workflows/deploy-website.yml` | فحص TypeScript وبناء `website/dist/` ونشره إلى Pages |

هذا الموقع ثابت ولا يحتوي Backend أو قاعدة بيانات أو حسابات أو مزامنة. تُخزّن الإعدادات والختمة في المتصفح، بينما يُطلب نص القرآن والتلاوة عند الطلب من الخدمة الخارجية الموثقة في `website/SOURCES.md`.

## مجلد Android `app/`

| المسار | الغرض |
| --- | --- |
| `AndroidManifest.xml` | تعريف حزمة Android والمكوّنات والأذونات الظاهرة في النسخة المفككة. |
| `apktool.yml` | إعدادات إعادة البناء التي أنشأها Apktool، مثل معرّف الحزمة وإعدادات الموارد. |
| `smali/`, `smali_classes2/`… | بايت كود Dalvik المفكك إلى Smali؛ ليس مصدر Kotlin/Java الأصلي. |
| `res/` | الموارد المفككة: واجهات XML، نصوص، صور، أيقونات ورسوم متحركة. |
| `assets/` | ملفات إضافية يستخدمها التطبيق، ومنها قواعد بيانات ووسائط وملفات SDK. وجود الملف لا يعني وحده أن الميزة مدعومة أو آمنة. |
| `lib/` | مكتبات native مجمعة لمعمارِيات Android مختلفة. |
| `kotlin/` | ملفات دعم/بيانات Kotlin المضمّنة مع التطبيق؛ لا تمثل شيفرة المصدر القابلة للتحرير. |
| `META-INF/`, `original/`, `unknown/`, `smali_assets/` | بيانات وملفات أبقاها أو أنشأها Apktool أثناء التفكيك. راجع ناتج البناء قبل حذف أي منها. |

## الحدود التقنية

- لا توجد هنا ملفات Gradle أو مشروع Android Studio تقليدي؛ بناء Android يتم باستخدام Apktool.
- تغييرات Smali منخفضة المستوى، وقد تكسر سلوكًا غير ظاهر. اجعلها ضيقة ومراجَعة.
- مجلدات `assets/` و`lib/` قد تضم مواد لطرف ثالث. تحقّق من شروطها قبل إعادة التوزيع.
- موقع الويب مستقل عن التطبيق وخدماته؛ مواعيده وإعداداته المحلية لا تتزامن مع Android.
- مخرجات `dist/` وملفات APK محلية متجاهلة في Git عادةً.
