# موقع المصلي للويب

## نظرة عامة

موقع React/Vite عربي RTL ثابت؛ يُبنى من مجلد `website/` ويُنشر عبر GitHub Actions إلى GitHub Pages. ليس بوابة خلفية ولا نسخة كاملة من خدمات Android. لا توجد حسابات أو قاعدة بيانات أو مجتمع متزامن بين المستخدمين.

## الصفحات

| المسار (داخل hash) | المحتوى |
| --- | --- |
| `/` | لوحة الصلاة: مواقيت اليوم، الصلاة القادمة، التاريخ، واختصارات الميزات |
| `/quran` | قائمة السور، البحث في السورة المعروضة، تشغيل تلاوة الآية، حفظ الآية ومتابعة آخر موضع |
| `/azkar` | أذكار صباح ومساء وما بعد الصلاة مع عدادات يومية محلية |
| `/qibla` | حساب اتجاه القبلة ودرجة الزاوية من الموقع المختار؛ يستخدم حساس الهاتف عند إتاحته |
| `/calendar` | تحويل التواريخ الميلادية إلى الهجرية وفق تقويم أم القرى |
| `/khatma` | عدد الأجزاء والصفحات اليومية المكتملة على هذا الجهاز |
| `/settings` | الاسم المحلي والمدينة/الإحداثيات وطريقة الحساب والإشعارات ومسح البيانات |

التنقل يستخدم hash routing (`/#/quran` ونظائره) لتجنب خطأ 404 على مسار المستودع في GitHub Pages.

## البيانات والخصوصية

تُحسب مواقيت الصلاة واتجاه القبلة داخل المتصفح بمكتبة `adhan`. لا يطلب الموقع إحداثيات دقيقة إلا بعد ضغط المستخدم على زر الموقع؛ ثم يستخدم الإحداثيات في الحساب المحلي. يخزن التطبيق تفضيلات المستخدم والمفضلات والتقدم في `localStorage`. لا توجد مزامنة، وقد يؤدي مسح بيانات المتصفح إلى فقدانها.

يعرض قارئ القرآن سورة واحدة عند الطلب من AlQuran Cloud (`ar.alafasy`) ويحتفظ اختياريًا بقائمة السور وآخر سورة في التخزين المحلي. يلزم الإنترنت إذا لم تكن السورة موجودة في ذاكرة المتصفح. لا ينسخ المستودع المصحف أو التلاوات كاملة. تظهر في صفحة الأذكار روابط حصن المسلم، وفي `website/SOURCES.md` المصادر والشروط كاملة.

إشعارات الويب لا تُرسل إلا بموافقة المستخدم، ويقتصر ضمانها على جلسة الصفحة؛ لا ينبغي الاعتماد عليها بعد إغلاق المتصفح. اتجاه البوصلة قد يتأثر بحساس الجهاز والحديد والمغناطيس القريب. التقويم الهجري قد يختلف عن إعلان الرؤية المحلية.

## تشغيل وبناء محلي

يتطلب Node.js 22 وpnpm 10:

```bash
cd website
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
VITE_BASE_PATH=/almosaly-open-source/ pnpm build
```

البناء إلى `website/dist/`. يضبط workflow بادئة الاستضافة `/almosaly-open-source/` ويحمّل artifact إلى GitHub Pages. قائمة المسارات المُعلنة متاحة في `website/public/manus-routes.json`، ويجب تحديثها عند تغيير مسارات الواجهة.
