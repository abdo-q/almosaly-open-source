# القيود والمشكلات المعروفة

هذه قائمة بقيود النسخة المفككة، وليست تأكيدًا بوجود عطل محدد في كل تثبيت. أبلغ عن مشكلة قابلة للتكرار عبر قالب Bug report.

- **ليست الشيفرة الأصلية:** Smali أقل قابلية للقراءة والصيانة من Kotlin/Java، وقد تكون التعديلات صعبة.
- **لا يوجد مشروع Gradle تقليدي:** البناء يعتمد على Apktool وأدوات Android Build Tools.
- **اختلاف التوقيع:** APK المعاد بناؤه يُوقّع بمفتاح محلي جديد، فلا يمكنه تحديث تثبيت موقّع بمفتاح مختلف.
- **الاختبار محدود:** نجاح التجميع أو CI لا يثبت سلامة مواقيت الصلاة أو GPS أو الإشعارات أو الصوت أو بقية وظائف التطبيق على الأجهزة.
- **اعتماد الخدمات الخارجية:** قد تعتمد بعض الوظائف على خدمات أو إعدادات أو واجهات خارجية لا يمكن ضمان استمرارها من ملفات المستودع وحدها.
- **مكونات الطرف الثالث:** وجود SDK أو مكتبة أو بيانات داخل APK لا يثبت ملكيتها للمشروع أو صلاحية إعادة توزيعها؛ راجع الأذونات والتراخيص قبل الاستخدام.
- **صور README:** صور واجهة تعريفية وليست جزءًا من اختبار التطبيق؛ راجع نسب المصدر وحقوق إعادة الاستخدام في README.

عند الإبلاغ، اذكر إصدار APK ومصدره، إصدار Android والجهاز، خطوات إعادة الإنتاج، والسلوك المتوقع والفعلي. لا تشارك إحداثيات دقيقة أو سجلات تحوي معلومات خاصة.
