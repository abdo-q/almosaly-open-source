# المصادر والإشعارات — موقع المصلي

هذا الموقع مفتوح المصدر وغير تجاري. لا يضمّن corpus كاملًا من القرآن أو ملفات تلاوة؛ عند اختيار سورة، يطلبها مباشرةً من AlQuran Cloud ويشغّل الصوت من CDN الخاص بالمصدر. يلزم اتصال بالإنترنت للتحميل الأول. شروط AlQuran Cloud تسمح بعرض/تضمين/تخزين نص القرآن للأغراض غير التجارية، وتوضح أن نصوصه مأخوذة من مصادر منها Tanzil وQuran Academy. نصوص القرآن تحفظ بالرسم والتشكيل كما يردان من الخدمة دون تعديل. التلاوات الموسيقية غير مستخدمة؛ الصوت تلاوة مشاري العفاسي، وتخضع لحقوق القارئ/الجهة المرخصة للمصدر وللاستخدام غير التجاري وفق شروط الخدمة. راجع الشروط الحالية قبل أي استعمال تجاري.

- AlQuran Cloud API: https://alquran.cloud/api
- AlQuran Cloud terms: https://alquran.cloud/terms-and-conditions
- AlQuran Cloud OpenAPI specification: https://api.alquran.cloud/v1/documentation/openapi/yaml

نصوص مختارة من حصن المسلم لقسم الأذكار، ويظهر رابط المصدر في الصفحة:

- أذكار بعد السلام من الصلاة: https://hisnmuslim.com/i/ar/25
- أذكار الصباح والمساء: https://hisnmuslim.com/i/ar/1

حساب مواقيت الصلاة واتجاه القبلة يستخدم مكتبة `adhan` الإصدار `4.4.6`، وهي متاحة بترخيص MIT. مواعيد الصلاة تتبع طريقة الحساب والإحداثيات والمنطقة الزمنية المختارة؛ ينبغي مراجعتها مقابل الجهة المحلية.

- المستودع والتوثيق الرسمي: https://github.com/batoulapps/adhan-js

صور واجهات التطبيق مأخوذة من أصول هذا المستودع، وشعار/أيقونة المصلي ولقطاته موثقة في README الرئيسي. يجب مراجعة حقوق صور التطبيق قبل إعادة استخدامها خارج سياق المشروع.
