# موقع المصلي

تطبيق ويب عربي RTL ثابت، مستقل عن خادم Android. يعمل على GitHub Pages؛ لا حسابات مستخدمين ولا مجتمع متزامن ولا قاعدة بيانات. التفضيلات والمفضلات وتقدم الختمة تبقى في `localStorage` على الجهاز.

## التطوير والبناء محليًا

يتطلب Node.js 22 وpnpm 10. من هذا المجلد:

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm typecheck
VITE_BASE_PATH=/almosaly-open-source/ pnpm build
pnpm preview
```

لمعاينة البناء على جذر استضافة محلية، يمكن حذف `VITE_BASE_PATH` من أمر البناء. في GitHub Pages تُبنى الملفات إلى `dist/` مع بادئة المستودع `/almosaly-open-source/`.

## المحتوى والخصوصية

تُحسب مواقيت الصلاة واتجاه القبلة داخل المتصفح بمكتبة `adhan` وباستخدام الموقع الذي يختاره المستخدم. طلب تحديد الموقع اختياري ولا يرسل الإحداثيات إلى موقع خارجي. القرآن والتلاوة يُحمّلان عند الطلب من AlQuran Cloud؛ لذلك يلزم الإنترنت لمحتوى غير محفوظ محليًا، وتخضع الخدمة لشروطها ومصادرها، الموضحة في [SOURCES.md](SOURCES.md). تعرض صفحة الأذكار مصادرها مباشرة.

يدعم الموقع التثبيت كتطبيق ويب (PWA) والتخزين المؤقت لهيكل الصفحات. إشعارات المتصفح مشروطة بالإذن وبقاء الصفحة مفتوحة؛ لا تعد بديلًا لتنبيهات تطبيق Android عند إغلاق الموقع. التقويم الهجري المعروض تحويل حسب تقويم أم القرى وقد يختلف عن إعلان الرؤية أو التقويم الرسمي المحلي.

الموقع لا يدّعي تطابقًا كاملًا مع كل خدمات Android، ولا يتصل بقاعدة بيانات أو بخدمة الحسابات. لحذف البيانات المحلية، استخدم زر **مسح بيانات هذا الجهاز** في الإعدادات أو إعدادات المتصفح.
